Species extension

https://vitalkultur.com/carlon-equine/fhir/StructureDefinition/animal-species

The extension on Patient that states the species. FHIR R5 has no species element on Patient, and a biometrics bundle that does not say which animal it describes is not interpretable.

This URI is an identifier. FHIR does not require it to be fetched — but a URI carrying the https:// scheme promises resolution, so it resolves. A bundle bearing the former base https://carlon.equine/… is a pre-0.3-final bundle: map the base across, nothing else changed.
